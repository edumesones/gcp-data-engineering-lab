**Presupuesto**

Interpretación de campos del presupuesto contrastada con la referencia oficial de la Cloud Billing Budget API
(https://docs.cloud.google.com/billing/docs/reference/budget/rest/v1/billingAccounts.budgets, consultada 2026-09-11):
`EXCLUDE_ALL_CREDITS` = "All types of credit are added to the net cost to determine the spend for threshold calculations";
`projects` = "usage from only this set of projects should be included in the budget";
destinatarios por defecto = "Billing Account Administrator and Billing Account User IAM roles for the target account"
cuando `disableDefaultIamRecipients` no es `true`.
